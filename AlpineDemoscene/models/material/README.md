# PhotoMat: нейросетевая генерация материалов

В `photomat-256.nam` находятся обученные веса PhotoMat, а не изображения
поверхностей. При запуске нативный D3D11-инференс получает случайный код,
строит 32-канальное поле признаков StyleGAN2 и преобразует его через MatUnet
в восемь каналов SVBRDF: высоту, diffuse RGB, шероховатость и specular RGB.
Веса модели обучены авторами на фотографиях реальных материалов со вспышкой.

Официальный проект: https://github.com/xilongzhou/PhotoMat

Статья: https://arxiv.org/abs/2305.12296

Размер экспортированных весов: **115 774 612 байт**. SHA-256:
`6d4706e0814ea7265e0f23b336c663ffbdcbaa47a893c2f8f96d7c6428e35257`.
Исходные checkpoints, ревизия кода авторов, преобразования формата и хеши
записаны в `provenance.json`.

## Реализация

`src/neural_material_runtime.cpp` выполняет mapping на CPU и свёртки через
`src/neural_material.hlsl`. Свёртки используют плитки 16×16 и разделяемую
память группы. Нужны только Win32, D3D11 и встроенные веса; Python, PyTorch,
CUDA, внешние DLL нейросетевых библиотек и сеть при запуске не используются.
Инференс работает в float32. Хранимые в исходном checkpoint случайные шумовые
карты исключены: шум создаётся заново из seed и умножается на обученные
коэффициенты. Используется truncation 0,7 к обученному среднему W.

Результат — три текстуры RGBA32F размером 256×256, каждая с девятью mip-уровнями:

- diffuse RGB в линейном пространстве и roughness в alpha;
- знаковая нормаль касательного пространства и height в alpha;
- линейный specular RGB, alpha = 1.

Нормали вычисляются из предсказанной высоты по формуле авторов. Specular
соответствует F0; при прямом освещении диффузная составляющая учитывает
множитель `(1 - specular)`. После чтения усреднённых mip-уровней нормаль
нужно нормализовать. Сам генератор использует нулевое дополнение границ,
поэтому бесшовное наложение решается кодом отображения материала на объекты.

`NeuralMaterialResult` и передача владения COM-объектами описаны в
`src/neural_material_runtime.h`. При отказе/отмене все выходные ссылки нулевые.
Callback возвращает 1 для продолжения и 0 для отмены. Ожидания GPU разбиты
на ограниченные dispatch-блоки и обслуживают callback.

## Воспроизведение

Для инструментов экспорта и проверки нужны Python, NumPy и Pillow.
Для нативной сборки нужны MSVC x64 и Windows SDK.

```powershell
python tools/neural_material_fetch.py
python tools/neural_material_export.py
./tools/neural_material_build_probe.ps1 -Out build/neural_material_probe42 -Seed 42
./build/neural_material_probe.exe models/material/photomat-256.nam build/neural_material_cs.cso build/neural_material_cancel 42 3
./build/neural_material_probe.exe models/material/photomat-256.nam build/neural_material_cs.cso build/neural_material_probe43 43 0
python tools/neural_material_validate.py
```

Загрузчик берёт два нужных элемента официального ZIP через HTTP Range,
проверяет длину, CRC и закреплённый SHA-256. Остальные модели архива не
скачиваются. Экспортёр читает pickle ограниченным декодером, который не
выполняет исходный код или классы из checkpoint. NumPy-проверка независимо
читает первоначальные веса, поэтому проверяет и перестановку тензоров NAM1,
и нативные операции.

В локальной проверке одно полное вычисление заняло около 9,9 секунды.
Максимальная ошибка относительно float32 NumPy для итоговых восьми каналов
составила 0,00004493, RMS — 0,00000197. Проверены отказ на усечённых весах,
неверной сигнатуре и смещении, отмена, повторяемость одного seed и отличие
другого seed. Полные данные и отпечатки исходников — в
`validation/neural-material.json`.

## Границы результата

Это безусловный генератор материалов, он не гарантирует нужную категорию
для произвольного seed и не генерирует геометрию объектов. При осмотре seed
42 похож на тёмный зернистый камень, seed 43 — на состаренную древесину.
Такая художественная классификация не является меткой модели.
Численное совпадение с эталоном не доказывает неотличимость от фотографии.

Лицензии авторов ограничивают применение некоммерческими исследованиями
и оценкой: `LICENSE-PhotoMat.txt` и `LICENSE-StyleGAN.txt`.
