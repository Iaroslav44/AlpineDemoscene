# ALPINE DREAMING — нейросетевая Windows-демосцена

Проект переводится на настоящую генерацию объектов предобученными нейросетями.
Предел единственного EXE — **строго меньше 400 000 000 байт**, включая веса,
шейдеры и код инференса. Сеть и внешние модели при запуске не используются.

**Это этап реализации нейрогенерации, а не завершённый фотореалистичный релиз.**
Окружение Альп пока использует прежние процедурные формулы. Нейросети сейчас
отвечают за форму человека, голову с цветом и вариациями выражения, а также
тембр скрипки, контрабаса и трубы. Кинематографический реализм, полная физика
человека/одежды и акустическая неотличимость от записи ещё не установлены.

## Запуск и оборудование

Запуск: `dist/AlpineDreaming.exe`. Escape отменяет загрузку или закрывает демо.
Начальная генерация требует времени; окно показывает индикатор активности.
После генерации объекты остаются в RAM/VRAM и анимируются каждый кадр.

Windows x64, Direct3D 11 Feature Level 11.0. CUDA не требуется. Проверочная
машина — Intel Iris Xe: 128 МиБ выделенной видеопамяти и до 7,82 ГиБ общей
системной памяти. Последняя величина не означает столько же свободной RAM.
Размер EXE также не равен расходу рабочей памяти. Время генерации и рендера
нужно смотреть в отчётах конкретной проверенной сборки.

Измерения текущей сборки на доступной Iris Xe:

| Проверка | Результат |
| --- | --- |
| Размер EXE вместе с тремя моделями | 31 750 144 байта |
| Свежий инференс тела + головы, seed 42 | 98,15 + 203,82 = 301,97 с |
| Контрольные кадры маршрута | 50 кадров, 1280 × 720, включая непрерывные участки |
| Медианное GPU-время кадра в диагностическом рендерере | 131,03 мс без физики и первого кадра |
| Полный нативный запуск, включая синтез музыки | Первые кадры замечены через 308,05 с; проверены 122 цикла рендера |
| Максимальный рабочий набор процесса в этой проверке | 689 217 536 байт; это не суммарный учёт памяти GPU |
| Отмена в начале загрузки | Корректное завершение за 1,94 с; проверка реакции окна за 500 мс не пройдена |

Диагностический рендерер включает D3D debug layer. Его GPU-время не выдаётся
за частоту кадров основного приложения. 128 МиБ выделенной памяти сами по себе
недостаточны: исполнение использует также общую системную память.

## Что вычисляется нейросетями

| Ресурс | Предобученная модель | Выход при запуске |
| --- | --- | --- |
| 200 | gDNA / THuman2.0, реальные сканы людей в одежде | Поле занятости, детальные нормали, 24 влияния скелета; затем извлечение сетки |
| 202 | GANHead / FaceVerse, реальные сканы голов | Геометрия, нормали, цвет поверхности, четыре направления выражения |
| 201 | MIDI-DDSP / URMP, записи настоящих инструментов | Параметры гармоник и шумового возбуждения; синтез банка нот в RAM |

Точные размеры и SHA-256: `models/runtime-manifest.json`. Для каждого пакета
есть исходный адрес, отпечаток checkpoint, перечень экспортированных тензоров
и ограничения. Значения обученных весов не заменены случайными числами.
Из исходных checkpoint исключены оптимизаторы, дискриминаторы и прочие
компоненты, не участвующие в выбранном графе исполнения.

Геометрия создаётся из latent-кода, зависящего от seed. Поля, меши и цветовые
значения не предвычислены в поставке. После извлечения меша удаляются отдельные
островки поверхности, чтобы случайный фрагмент не определял масштаб человека.
Текущий прототип создаёт одну форму тела и одну голову на запуск, затем
использует их для шести жителей. Это ещё не шесть независимо созданных личностей.

В мимике используются четыре главные компоненты численных параметров реального
исполнения: они описывают около 86,24% вариации его 50 параметров выражения.
Геометрические направления этих изменений вычисляет обученная сеть. Сохраняются
только численные управляющие кривые, без кадров исходного видео. Это сокращённая
модель выражения; полная система FLAME и мышечная симуляция не реализованы.

Цвет GANHead — обученное представление внешнего вида скана, а не восстановленный
полный набор физических PBR-свойств. Материалы тела пока заданы вручную.
Нормали выражения пока не пересчитываются отдельной нейросетью каждый кадр.

Музыка сохраняет MASM-партитуру и house-ритм. Встроенная сеть вычисляет тембр;
высота, атаки и выразительные управляющие кривые задаются партитурой. Исходная
полоса модели соответствует 16 кГц. Выход пересчитывается в 44,1 кГц, что не
восстанавливает отсутствующие высокие частоты. Подробнее: `AUDIO_RU.md`.

## Исполнение

Win32-хост, планировщик и микшер — x64 MASM. Инференс геометрии — HLSL compute;
управление вычислениями и извлечение сетки — небольшой нативный модуль C++.
Аудиодекодер — нативный SSE2. Эти модули статически включаются в EXE без CRT,
Python, TensorFlow, PyTorch или ONNX Runtime. Это не реализация всех модулей
исключительно на ассемблере; состав исходников указан явно.

Основной кадр, отражение и тени используют сгенерированные сетки. Старый SDF-слой
лица удалён из активного рендера. Рельеф, деревья, поселение, вода, облака и
планеры пока сохраняют предыдущие процедурные генераторы и сокращённые
физические модели (`PHYSICS_RU.md`).

Растровые файлы `reference/lookdev/` являются только прежними референсами.
Программа их не читает. Сборка проверяет отсутствие готовых изображений и видео
в ресурсах, а для весов проверяет точные ID, размеры, заголовки и хеши.

## Сборка и проверка

Требуются Visual Studio C++ Build Tools (включая ml64) и Windows SDK с fxc/rc.
Все необходимые для сборки экспортированные веса уже находятся в `models/`.
Разработка/повторный экспорт требует Python с NumPy; конечному пользователю
Python не нужен.

```powershell
.\build.ps1 -KeepIntermediates
.\tools\verify.ps1 -Executable .\dist\AlpineDreaming.exe
.\tools\verify_selftest.ps1
.\tools\build_probe.ps1
.\tools\build_audio_probe.ps1 -Out build/neural_audio_fullscore
.\build\render_probe.exe --exe dist/AlpineDreaming.exe --out build/neural_final_timeline --avatar-seed 42 --times-file tools/neural_release_times.txt
.\tools\native_smoke.ps1 -HoldSeconds 600 -MinimumRenderedFrames 120 -ReportPath build/native_playback_400.json
```

Численная проверка сравнивает native/HLSL-инференс с независимым вычислением
исходного графа. Она отдельно проверяет перенос номеров костей, геометрию,
нормали, цвет и выражения. Проверка нативного процесса требует реально
завершённых циклов рендера: одно лишь ожидание внутри загрузки не считается успехом.
Тестовые дампы и кэши находятся в игнорируемом `build/`; runtime их не использует.

Актуальный отчёт выпуска: `validation/400mb-release.json`, сформированный
для текущего EXE. Отчёты `88mb-release.json` и `validation/history/` относятся
к прошлым версиям и не подтверждают текущую сборку. Численные тесты не являются
оценкой фотореализма; необходима отдельная визуальная и слуховая проверка.

Исходная версия сохранена тегом `alpine-before-neural-400mb-20261029`.
Текущая работа ведётся в ветке `alpine-neural-400mb`.
