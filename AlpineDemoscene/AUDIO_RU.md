# Нейросетевой синтез инструментов — 29 октября 2026

При запуске демо CPU исполняет предобученную тембровую ветку **MIDI-DDSP**.
Исходный checkpoint обучен на URMP — записях настоящих акустических
инструментов. Скрипка, контрабас и труба используют обученные
идентификаторы 0, 3 и 9. В EXE встроены веса; звуковой банк создаётся
заново в памяти. Записи исполнения и готовые сэмплы в поставку не входят.

**Акустическая неотличимость от живых симфонических инструментов не
подтверждена.** Нативная частота синтеза исходной модели — **16 кГц**.
Преобразование в 44,1 кГц не восстанавливает отсутствующие высокие частоты.
Контрабас не заявляется как отдельно обученная модель pizzicato.
Разнообразие артикуляций и убедительность ансамбля требуют прослушивания;
точность вычислений сети этого не доказывает.

## Выполнение при запуске

`src/alpine.asm` загружает ресурс **201** и вызывает `NeuralAudioInit`.
Ресурс `models/audio/midi_ddsp_timbre.nad` содержит **2 348 926** настоящих
обученных параметров float32 без квантования; размер — **9 395 768 байт**,
включая 64-байтный заголовок. SHA-256:

```text
807425787be973d97639d11010f9f84d0022a822fc66af35e420bc70cc0d4f92
```

`src/neural_audio.cpp` исполняет операции самостоятельно на CPU с SSE2.
Он статически линкуется с MASM-приложением и не требует TensorFlow,
Python, CUDA, отдельной библиотеки инференса или CRT при работе демо.
Для выделения памяти используются существующие функции Windows.

Сеть включает пять полносвязных слоёв шириной 512, обученное представление
инструмента и двадцать остаточных свёрток со 128 каналами и растущим внутри
каждого блока шагом выборки. Она предсказывает громкость, распределение
60 гармоник и 65 полос шума с частотой управления 250 Гц. Гармонический
синтезатор и меняющийся во времени FIR-фильтр шума превращают эти параметры
в звук. Затем 32-отводный полифазный интерполятор подавляет спектральные
копии при преобразовании 16→44,1 кГц.

Высота ноты, вибрато, громкость, яркость, атака, положение внутри ноты
и остальные исполнительские параметры задаются партитурой.
**Отдельные обученные генераторы высоты и выразительности оригинального
MIDI-DDSP здесь не исполняются.** Из checkpoint также исключены анализатор
входной записи и обученный ревербератор. Реализация представляет собой
управляемый нейросетевой синтезатор тембра, а не полный оригинальный
MIDI-DDSP или нейросетевой композитор.

## Банк и музыкальная постановка

MASM-функция `OrchestraMakeSample` вызывает нативный декодер для 18 нот
длительностью 4,5 секунды: девяти в скрипичном регистре, четырёх для
контрабаса и пяти для трубы. Разные ноты получают независимые
детерминированные seed возбуждения. При ошибке инференса оркестровая
генерация прерывается; прежний модальный синтезатор не подставляется.

`src/orchestra.inc` сохраняет авторскую house-аранжировку при 120 BPM:
гармонии Am9–G6/9–Fmaj9–Em7(add11), перекрывающиеся скрипичные аккорды,
синкопированный бас, редкие ответы трубы и процедурную ритм-секцию.
Три скрипичных голоса раскладываются на двенадцать виртуальных исполнителей
со сдвигами начала, панорамы и высоты. Повторное использование банка
ограничивает естественность переходов между нотами и артикуляций.

Стереоревербератор остаётся авторским DSP: четыре линии задержки,
рассеяние Хаусхолдера, частотное затухание и обратная связь 0,69.
Он не обучен на акустике зала. Пиковый запас рассчитывается по полной
партитуре перед переводом в PCM.

Основные буферы: банк **14 288 400 байт**, временный стереомикс
**45 158 400 байт**, финальный PCM **22 579 200 байт** для 128 секунд
stereo16 при 44,1 кГц. Дополнительная временная память нейросетевого
синтеза ограничена 14,5 МБ при максимальной поддерживаемой длине входа;
для текущей ноты она меньше. Банк и временный микс освобождаются после
формирования партитуры. Сгенерированные данные не увеличивают EXE.

Генерация регулярно вызывает callback обработки сообщений окна:
`1` продолжает работу, `0` отменяет. Неполный сэмпл не считается успешно
созданным; временные буферы освобождаются при отмене.

## Воспроизведение проверок

Обычная сборка использует уже экспортированный NAD1 из репозитория.
Для повторного получения весов нужны Python с NumPy и доступ к официальному
архиву только на этапе разработки:

```powershell
python .\tools\neural_audio_fetch.py
python .\tools\neural_audio_export.py
.\tools\neural_audio_build_probe.ps1
python .\tools\neural_audio_validate.py
```

Загрузчик проверяет закреплённый SHA-256 архива; экспортёр дополнительно
проверяет index/data checkpoint. Ограниченный читатель TensorFlow SSTable
извлекает float32-тензоры без запуска TensorFlow, pickle или кода модели.
Тензоры, смещения и исходные хеши перечислены в `models/audio/provenance.json`.

Для проверки всей производственной партитуры:

```powershell
.\tools\build_audio_probe.ps1 -Out build/neural_audio_fullscore
python .\tools\verify_audio.py --directory build/neural_audio_fullscore
```

Нужны MSVC/MASM, Windows SDK, NumPy и ffmpeg. `audio_probe.cpp` вызывает
те же `GenerateSineTable` и `GenerateAudio`, что основная программа,
с тем же встроенным ресурсом 201. Он не создаёт графическое устройство
и не открывает звуковую карту. Результаты — полный WAV, 24-секундный
фрагмент, отдельные ноты и JSON-метрики в указанной папке.

Проверено следующее:

- Нативные выходы нейросети сравнены с независимым NumPy-графом,
  читающим первоначальный checkpoint: максимальная абсолютная ошибка
  **6,44×10⁻⁶**, RMS **1,01×10⁻⁶**.
- Изменение идентификатора инструмента меняет предсказанный спектр.
  Повреждённый заголовок, усечённый ресурс и отмена обрабатываются.
- Отдельная нота 4,5 секунды создавалась примерно за **0,4–0,7 секунды**
  на проверявшемся CPU; это измерение конкретного компьютера.
- Полная партитура проверяется на конечность банка, клиппинг, DC,
  высоту контрольных нот и нулевые края петли. Актуальное время,
  громкость, пики, SHA-256 и отпечатки исходников сохранены в
  `validation/neural-audio-fullscore.json`.

Сравнение сети и её источники зафиксированы в `validation/neural-audio.json`.
Численные проверки не устанавливают неотличимость от записи живого оркестра.
Старые отчёты модального синтезатора не являются проверками этой версии.
